📷 Passport Photo Maker

Upload a photo. Processing happens directly in your browser; your original photo is not uploaded to a server.

On phones that support file sharing, “Share File to WhatsApp” shares the actual JPG file. A website cannot force WhatsApp Desktop to accept a file attachment without WhatsApp's own API.

📁 Multiple Files

Select multiple files at once and process them directly in the browser.

Supports multiple JPG/PNG/WebP, PDF, TXT, CSV, HTML and DOCX files. On supported mobile browsers, Send All Files opens the share sheet so WhatsApp can receive the actual files.
